## 0.2 v4 设计目标（存档）

v3 版本内容约 1–2 天消耗完毕，v4 的核心目标是**把有效游戏时长拉长到 2–3 个月**，手段：

| 手段 | 内容 |
|---|---|
| 经验曲线加深 | `25 × L^1.95`，单技能 1→60 级累计约 145 万经验 |
| 档位加密 | 采集 5 系全部 7–8 档（Lv.1 → Lv.56），制造 5 系共 39 个配方 |
| 装备纵深 | 武器 7 把（铁剑→轩辕神剑）、防具 7 件、新增**饰品槽** 4 件 |
| 强化上限提升 | +15 → **+20**，新增第 4 档强化材料「乾坤灵晶」 |
| 无限爬塔 | **秘境系统**：指数成长怪物 + 秘境币 + 永久心得商店 |
| 成就系统 | **28 个成就**，达成即永久生效（经验/铜钱/攻防加成） |
| 轮回系统 | 总等级 300 可转生，轮回点永久加成，多周目循环 |

## 1. 核心循环

```
采集（采药/采矿/伐木/打猎/钓鱼，各 7–8 档）
   ↓ 原料 + 副产物（兽皮/兽骨/兽筋/内丹）
制造（炼丹 8 方 / 锻造 12 谱 / 烹饪 8 味 / 制衣 7 甲 / 强化 4 石）
   ↓ 药品 / Buff 丹 / 装备 / 食物 / 强化石
战斗（6 张图 12 种怪，4 流派 × 5 招式）＋ 秘境爬塔（无限层）
   ↓ 铜钱 / 材料 / 装备 / 秘境币
秘境商店（永久心得 + 饰品）→ 成就加成 → 轮回 → 二周目加速
集市交易 → 门派任务（63 种自动生成）→ 武林令 → 良性循环
```

- 动作按周期循环执行，每周期产出物品 + 技能经验；概率产物独立判定
- 加工类动作消耗原料，原料耗尽自动停止并提示
- 离线照常结算采集（上限 8 小时），离线不结算战斗、回满气血
- 存档版本 **v4**（`wuxia-idle-save-v4`），存 localStorage

### 分解炉（集市）

- 任意非货币物品可分解：返还 **40% 市价**铜钱（出售为 70%，分解是带损耗的回收）
- 市价 ≥200 的珍品额外炼出 🔮 **玄晶**：`1 + floor(市价 / 1000)` 个
- 玄晶本身市价 150，是高价值物品的"精华化"储存手段

### 炼化转换（炼丹）

- 10 个炼化方，低阶材料 **4:1**（部分 3+1）损耗转化为高阶：甘草→何首乌→灵芝→雪莲；铜→铁→玄铁→陨星铁；松→柏→紫檀→沉香木；人参+朱果→九叶灵芝
- 定位：溢出材料出口 + 高阶材料救急

### 强化成功率

| 强化区间 | 消耗材料 | 单次成功率 |
|---|---|---|
| +1 ~ +5 | 强化石 | 95% − 8%×N |

- 失败不碎装备、不掉级；强化成功给强化技能经验（10 × 当前强化值）

### 6.2 伤害公式（每 2 秒一回合）

```
基础伤害 = max(1, 玩家ATK − 怪物DEF × 0.6)   （剑法 Lv.15 破岳剑意：DEF 部分 ×0.7）
× (1 + 0.05 × 已解锁招式数)                  （4 流派通用，5 招式全解锁 +25%）
× (1 + 0.03 × 秘籍参悟层数)                  （boss 掉残页，每流派 5 层圆满 +15%，轮回保留）
× 流派特性：剑 10% 暴击 ×1.8 ｜ 拳 15% 连击 ｜ 暗器首回合 ×1.25 ｜ 内功吸血 8%
× 随机浮动 0.85 ~ 1.15
怪物反击 = max(0, 怪物ATK − 玩家DEF) × 0.85~1.15
击杀经验 = 怪物HP/4，按 流派 40% / 攻击 30% / 防御 20% / 气血 10% 分账
```

| 门槛 | 总等级 ≥ 300 |
| 轮回点 | `floor(总等级 / 100)`（保底 3 点） |
| 每点收益 | 经验 +5%、铜钱 +3%（永久，跨周目累加） |
| 重置 | 技能等级、背包、装备、任务、秘境当前层 |
| 保留 | 成就及加成、轮回点、秘境心得与饰品、生涯纪录（击杀/制造/最高层）、聊天 |

**多周目加速：** 一周目裸奔；二周目带 3 点轮回点（+15% 经验）+ 成就加成 + 秘境心得，冲级速度约为一周目 1.3–1.5 倍；七周目叠加 +35% 轮回成就后进入收割期。

## 11. 内容消耗量测算（核心）

### 11.1 假设

- 玩家采用「当前可做的最高档动作」，经验速率随档位提升：前期 ~2 xp/s → 中期 ~10 xp/s → 后期 ~15 xp/s
- 有效挂机时长按 16 小时/天计（离线上限 8h + 在线活跃）
- 悟道茶与成就/轮回加成已折算进平均速率

### 11.2 单技能养成耗时

| 阶段 | 累计经验 | 平均速率 | 纯挂机耗时 | 折合天数(16h/d) |
|---|---|---|---|---|
| Lv.1 → 30 | 18.4 万 | ~5 xp/s | 10.2 h | < 1 天 |
| Lv.1 → 50 | 84.6 万 | ~8 xp/s | 29.4 h | ~2 天 |
| Lv.1 → 60 | 145.5 万 | ~10 xp/s | 40.4 h | ~2.5 天 |

### 11.3 全局消耗模型

| 内容线 | 规模 | 估算耗时 |
|---|---|---|
| 5 个采集系全档位解锁（Lv.56+） | 5 × ~120 万 xp | 每系 ~2.5 天，**合计 ~2 周**（并行推进折半） |
| 5 个制造系配方全解锁 | 与采集链耦合，受原料制约 | **~2–3 周** |
| 战斗 7 技能（4 流派 + 攻防血） | 击杀经验 = HP/4 分账 | 跟随装备进度，**贯穿全程** |
| 装备毕业（轩辕神剑 + 天罡战甲 + 强化 +20） | 强化 +16~20 平均 ~30 次尝试/级 | **~2–4 周**（乾坤灵晶产出是瓶颈） |
| 秘境爬塔 | 30 层 ≈ 二周目；50+ 层 ≈ 四周目 | **长期目标** |
| 28 成就全收集 | 含 100 层秘境、1 亿铜钱、7 次轮回 | **~2–3 个月** |
| 轮回循环 | 一周目到总等级 300 约 **3–4 周**；之后每周目加速 | 7 周目 ≈ **2.5–3 个月** |

### 11.4 结论

- **一周目**（无轮回直冲）：全技能解锁 + 装备成型 ≈ **4–6 周**
- **完全体**（7 轮回 + 全成就 + 秘境 60+ 层）：≈ **10–12 周**
- 对比 v3（1–2 天消耗完），v4 内容量提升约 **30–40 倍**，达到 2–3 个月设计目标
